# Product

<!-- impeccable:product-schema 1 -->

## Platform

adaptive

## Stack

Vite, React, TypeScript, Tauri

## Users

Casual readers building a premium personal library for focused reading.

## Product Purpose

To provide a fully offline, private library with universal format support (PDF, EPUB, TXT) where users can focus on their reading.

## Positioning

A fully offline, private library with universal format support that feels like a beautifully designed, immersive reading experience akin to premium native apps.

## Operating Context

Users manage and consume their book collections locally on desktop and web environments, treating the application as a dedicated, private space for reading and curation.

## Capabilities and Constraints

- Universal format support: PDF, EPUB, TXT.
- Must remain fully offline and local-first.
- Absolutely NO external dependencies (e.g., no external web fonts).
- Users can edit book metadata and custom cover photos.
- Tracks reading progress and formats.

## Brand Commitments

- Preserve the existing "Digital Library" premium aesthetic and structural layout.
- Maintain a quiet, literary atmosphere with sophisticated typography and strong editorial composition.

## Product Principles

1. **Absolute Privacy:** Everything stays on the local device with zero external dependencies.
2. **Premium Craft:** The interface must feel like a curated digital bookshelf, not a generic web dashboard.
3. **Immersive Focus:** The reading experience should prioritize the content and minimize distractions.
